# PRism

AI-assisted Pull Request Risk & Merge Governance Platform.

PRism combines deterministic repository evidence, TypeSafe Jev judgment, and versioned policies into GitHub-native SAFE / REVIEW / BLOCK checks.

Implementation is being delivered as one small functional commit per pull request. Local validation precedes live installation; GitHub App and Jev credentials are not yet configured.

See [architecture decisions](docs/adr/0001-evidence-first-governance.md) and [official-source research](docs/research/official-sources.md).
